# Seoul_Compass_AI_2026

이곳은 서울 관광을 위한 여행 가이드 개발을 위한 사이트입니다.

서울 명소를 탐색하고, 취향에 맞는 코스를 설계하고, AI 가이드에게 여행 질문을 하는 **정적 웹 프로토타입**입니다. GitHub 저장소가 메인(원본)이고, 로컬 폴더는 백업용 복제본입니다.

## 주요 기능

- **명소 탐색** — 23곳의 샘플 데이터를 카테고리(궁궐·한옥 / 문화·예술 / 자연·공원 / 야경·전망 / 맛집·카페 / 쇼핑)와 검색어로 필터링
- **서울 개략 지도** — 실제 좌표를 자체 SVG 지도에 매핑한 마커. 마커/카드 클릭 시 상세 정보(modal) 확인
- **코스 설계** — 명소를 코스에 담고 순서·이동 거리·예상 소요 시간 확인. 평점과 거리 기반 자동 추천
- **AI 컨시어지** — 외부 API 없이 동작하는 규칙 기반 추천 엔진. "코스 짜줘", "비 와! 실내로 재조정", "야경 명소", "지하철 정보" 등에 응답
- **실내/실외 필터, 계절 추정 날씨, 한국어/영어 전환, 다크/라이트 테마**

> ⚠️ 수록 정보는 **데모용 예시 데이터**입니다. 실제 운영 시간·요금·교통 정보는 반드시 공식 출처에서 확인하세요.

## 실행 방법

별도 설치가 필요 없습니다. 아래 중 하나를 사용하세요.

전용 포트 **9200**을 사용합니다. 다른 프로젝트의 8000/8001/8010/8080/8787, 9100~9103 대역과 겹치지 않습니다.

```powershell
# 방법 1: Python 서버 (권장)
python server.py
# → http://127.0.0.1:9200

# 방법 2: Python 내장 서버
python -m http.server 9200

# 방법 3: index.html을 브라우저에서 직접 열기
```

다른 포트가 필요하면 `python server.py 9201`처럼 번호를 인자로 넘기세요. 포트가 이미 사용 중이면 사용 가능한 다른 번호를 안내합니다.

`index.html`을 직접 열어도 모든 기능이 동작합니다.
