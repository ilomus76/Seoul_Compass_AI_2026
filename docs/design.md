# 디자인 시스템 ( Visual Navigator )

## 1. 색채 팔레트
- 배경: 딥네이비 `#070b16` + 보라/민트/코럴 오로라 그래디언트
- 주 강조: 민트 `#4fe0c4`, 보라 `#7c5cff`, 골드 `#ffc857`, 코럴 `#ff6b8a`, 스카이 `#58c8ff`
- 방향 8색: `#ff6b8a · #ff9f68 · #ffd166 · #8fe388 · #4fe0c4 · #5ab0ff · #8a8bff · #cf8bff`
- 업종 14색: 등산/샤워/약속/식사/볼링/국제관광/지하철/쇼핑/명소/야경/공원/카페/문화/주점 각각 지정

## 2. 타이포그래피
- 본문: Pretendard → Apple SD Gothic → system-ui
- 수치: `ui-monospace, Consolas` (KPI·점수·거리)
- 계층: h1 27px / h2 17px / 본문 12px / 캡션 9~10px

## 3. 컴포넌트 규칙
- 카드: 반경 18px, 글래스 배경 `backdrop-filter`, 상단 그라데이션 라인(섹션별 색상)
- 버튼: primary(그라데이션), ghost(투명+테두리), danger(코럴)
- 차트: 도넛/막대/스파크라인/히트맵 모두 인라인 SVG·CSS (외부 라이브러리 없음)
- 지도: 자체 위경도 투영 SVG + 한강/자치구 배경, 8방향 부채꼴·반경원·마커·경로
- 상태: toast 하단 중앙, 3초 후 자동 숨김

## 4. 화면 구성 (7개)
1. 일정 만들기 — 자연어 입력, 출발지/반경/날짜/이동수단/예산, 가중치
2. 360도 방향 분석 — **위경도 지도에 8방향 부채꼴·반경원·마커·경로를 매핑**한 지도 보기 ⇄ 극좌표 컴패스 보기 전환, 방향 점수
3. 데이터 개요 — KPI 5종 + 차트 4종
4. 시간대별 일정표 — 행 선택 상세, 시간 수정, 장소 변경
5. 추천 경로 TOP 3 — 등급별 색상 카드
6. AI 기대치 리포트 — 근거·주의·대체·신뢰도
7. 나의 여행 기록 + 설정 — 일정/방문 기록, 가중치·테마·연동 상태

## 5. 반응형
- 모바일 우선, 700px 이하에서 차트/설정 1열, 지도 전체 폭
- PC는 최대 폭 1200px 중앙 정렬

## 6. 접근성/주의
- 색상만으로 의미를 전달하지 않고 라벨· legends를 함께 표시
- 확인되지 않은 비용/이동시간은 추정치로 명시
