# SBOM (소프트웨어 자재 명세)

| 구성요소 | 버전 | 라이선스 | 용도 |
|---|---|---|---|
| Python | 3.12.10 | PSF | 백엔드 런타임 |
| FastAPI | 0.115.0 | MIT | API 서버 |
| uvicorn | 0.30.6 | BSD-3-Clause | ASGI 서버 |
| Pydantic | 2.x | MIT | 스키마 검증 |
| HTML5/CSS3/JavaScript | - | - | 프론트엔드(외부 프레임워크 없음) |
| SQLite | 내장 | Public Domain | 여행 기록 저장 |

데이터: `data/sample_places.json`은 데모용 예시 데이터이며 실제 공공 API 데이터가 아닙니다.
외부 이미지/폰트/지도 SDK는 현재 사용하지 않습니다. 도입 시 이용약관 확인 후 이 문서를 갱신합니다.
